# 换机只带说明文件夹够不够

不够。说明定义流程，实际恢复还需要对应材料：

| 材料 | 为什么需要 |
|---|---|
| 审定的完整代码树与提交/哈希清单 | 应用、迁移、页面和后台版本保持一致；不把.git或钥匙包混入公开源码包 |
| 权威钥匙包中的当前有效env/原密钥与口令 | 历史卡密解密、身份HMAC、授权/发布验签和备份解密继续有效 |
| 经确认的正式数据库.enc | 恢复当前客户软件、卡密、额度流水、设备绑定及审计；旧测试dump不能替代 |
| 若有本站发布包：对象存储文件与清单 | 数据库备份不包含安装包本体 |
| 目标域名/DNS和受控访问条件 | 由08的安装器接证书、代理及维护服务 |

当前正式平台有业务，迁移时保留旧站和原材料，先在隔离/空目标恢复并核对，再经确认切换。文件存在、包能解密或安装成功都不能单独证明历史客户恢复完成。

步骤统一看 [08](08-完整部署SOP.md)，恢复前置看 [03](03-新VPS怎么装怎么导备份.md)，取钥匙先按 [06](06-密钥在哪.md)。
