# 展示站界面候选

这是2026-11-17按负责人反馈制作的本地交互预览。入口 index.html，本机地址 http://127.0.0.1:8790/。负责人已于2026-11-17确认该方向并授权正式部署。这里保留确认依据，不是另一套运营网站，也不是Django实现入口；正式维护源为templates和static。

运行：在项目根使用 `.venv/Scripts/python.exe 展示网站/界面预览/start-preview.py`。只监听本机，不连接数据库。关闭服务后链接失效，启动同一脚本即可恢复。

## 候选方向

深蓝顶栏、横向分类、蓝色截图承托和开放图文目录。去掉原重复小标题及通用侧栏介绍；完整介绍、图片内箭头、放大、下载和购买入口保留。桌面动作位于整行右下，手机图上文下。页尾始终有总数和页码，只有一页时前后页不可点击，多页链接保留搜索和分类。

完整介绍和页脚不截断、不折叠、无内部滚动框。支持左右键、Escape、触屏切图；减少动态效果时关闭切图揭示动画。

此目录保留定稿时的视觉快照，正式DESIGN.md已按批准方向更新；不修改检测忽略项掩盖发现。正式模板和设计文档已按批准方向原位适配；管理后台维持原布局，正式上线结果以STATUS及部署记录为准。

## 内容边界

本机 data/catalog.json 和两张WebP是从正式站公开页面及 /image/2/、/image/3/ 读取的快照，由现有data忽略规则排除。保留用户上传原图，内容是否对应由所有者维护。下载/购卡只提示去正式站操作，不执行跳转。

90条分页测试软件、长分类、长页脚仅在测试浏览器里拦截请求临时注入，未写数据库或默认快照，不出现在正常预览中。
