# 展示网站

可独立复制的软件展示网站，包含公开目录和内容管理后台。与授权平台无接口、无共享账号或密钥。前台采用负责人定稿的深蓝顶栏、横向分类和完整图文目录，图片左右叠放切换箭头；单页同样显示分页。正式站为https://showcase.example.com。

## 本地快捷入口

Windows安装 Python 3.12 后，双击 `创建管理员.cmd`，按提示创建自己的账号；然后双击 `启动本地网站.cmd`。首次会安装本项目依赖。默认前台 `http://127.0.0.1:8770/`，后台 `/manage/`。终端窗口关闭后本地服务停止。

默认是空站点，没有默认账号、密码或示例软件。日常数据在忽略提交的 `data/local/`，不能作为代码垃圾清理。

## 开发验证

```powershell
$env:SITE_DEBUG='1'
.venv\Scripts\python.exe manage.py test catalog
```

正式环境必须 HTTPS，不能把 runserver 暴露到公网。部署材料位于本项目 `deploy/`，执行入口为 `deploy/install-site.sh`；不要运行上级授权系统的部署器。
