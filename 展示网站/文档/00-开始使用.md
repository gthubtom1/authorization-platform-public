# 开始使用

这是完整的独立网站，HTML预览已转为真实数据。整个“展示网站”目录可以复制，前台和管理端都在其中；不需要复制上级授权系统。

## 在自己电脑使用

1. 安装 Python 3.12，勾选加入 PATH。
2. 双击 `创建管理员.cmd`。首次自动建立本项目虚拟环境并安装依赖；依次输入账号和自己设置的密码。密码输入时不显示，属于正常情况。
3. 双击 `启动本地网站.cmd`，窗口保持打开。
4. 浏览器打开 `http://127.0.0.1:8770/` 看前台；`http://127.0.0.1:8770/manage/` 管理内容。
5. 先创建分类，再添加软件。名称、介绍、至少一张图和两个有效网址齐全后选择“已上架”并保存。

只想先填一部分时选“草稿”。上架前可从编辑页打开“预览已保存内容”，这不是访客详情页。

## 数据与账号

本地资料在 `data/local/`，数据库为 `site.sqlite3`，图片在 `media/`，本地session密钥在 `local-secret.txt`。不要删除或分享这个目录；代码提交不包含它。

没有默认管理员。忘记密码，在网站目录运行（已设置本地环境后）`.venv\Scripts\python.exe manage.py changepassword 你的账号`。需要先将 `SITE_DEBUG=1` 和 `SITE_DATA_DIR` 指到原 `data/local`，不可指到验收数据库。

当前工作会话可另有 `data/acceptance/` 供验收，不是正式内容。只有显式设置 `SITE_ALLOW_DEMO=1` 且数据库为空时才能运行 `manage.py seed_demo`，它会在页面标明本地示例。正式部署不要运行这个命令，也不要带验收数据。
