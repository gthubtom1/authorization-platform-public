# 正式站与接入测试边界

现行唯一平台：`https://auth.example.com`，IP `192.0.2.10`。旧 `https://legacy.example.com` 在原机器保留兼容反代，所有请求仍到同一新账本，不是第二套授权站。新下载JSON的base_url使用新域名，验签公钥和既有软件身份保留。香港测试站 `https://retired.example.com` / `192.0.2.12` 已过期，不能连接或发卡，test_downstream_a 仅为历史账号。

新软件按 00：后台创建、下载自己的 JSON、在软件项目使用模板副本。普通接入不需要服务器钥匙或后台管理员凭据。

正式站接入测试只用已有 test_downstream_b，在当前软件创建 test_only/0 成本测试套餐、开放经营范围后，由 test_downstream_b 发卡。禁止改 test_downstream_a / test_downstream_b 密码，禁止重置、新建测试下游或使用真下游额度。测试卡不写入配置/文档/Git。

平台侧查登录凭据须先读权威钥匙包 README 的“从这里开始”；测试下游口令索引为 07-接入测试下游口令，明文不属于软件接入材料。现行总账在同一钥匙包 12-平台登录凭据总账.md，禁止猜口令。

部署、SSH、密钥复用、备份只看根目录 部署与恢复/，不能把旧测试站的 Nginx 或历史包当成当前环境。软件侧验收先用本地隔离夹具；真机挤机需两台机器，缺条件如实记录，不能拿静态预览代替。
