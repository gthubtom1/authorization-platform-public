    就地改版本号？

    用于「网盘地址不变、只换了文件」的情况：把版本号往上改（例如 2.0.8 → 2.0.9），客户端下次检查就会提示更新，而且不会新增一条版本历史。 仅网盘发布可直接改号。本站安装包请重新构建、签名并发布。新号须高于同通道其他已发布版本。
