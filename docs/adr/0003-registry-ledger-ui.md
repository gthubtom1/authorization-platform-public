# ADR-0003：Registry / Ledger Control Room UI

状态：accepted

## 决定

UI 使用“授权控制室 / 额度账本”作为视觉和交互主题，采用矿物灰、深墨蓝、信号蓝、账本黄、停止珊瑚和松针绿；使用窄标题字体、中文正文和等宽数据字体。

## 原因

管理员和下游的核心任务是判断状态、成本、影响范围和历史，不是浏览营销内容。界面需要体现控制、账本和授权脉络，而不是通用 SaaS 卡片模板。

## 影响

单卡/单码关键详情按现行UI合同提供授权脉络线，其他对象不因此新增通用时间线；生成、回收、撤销等操作必须在确认前展示成本和不可逆影响；具体令牌和页面规则见 `docs/UI-DESIGN-SYSTEM.md`。
