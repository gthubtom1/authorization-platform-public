# ADR-0005：零基础操作、真实验收与凭证显示规则

- 状态：accepted
- 日期：2026-08-19
- 领域：产品逻辑、UI、验收、持续开发

## 已确认的长期产品规则

这些规则来自旧授权平台任务的反复确认，作为产品决策保存，不保存旧聊天全文：

- 先在本地修改、测试、真人式验收并创建检查点，VPS 只接收本地已验证的固定版本。
- 下游账号的最小身份是用户名和密码；管理员直建不需要邀请码、内部标识或显示名称。
- 邀请码独立于账号生成，可以批量、无限批次生成；每枚只在注册成功时消费一次。注册失败不创建账号、不消费邀请码，历史处理记录可清理。
- 活跃数据先归档；归档停止登录和业务权限但保留列表；只有归档对象可以彻底删除。审计、额度流水和追责历史不可删除。
- 卡密、邀请码、额度兑换码等敏感凭证按权限可再次显示/复制/下载；密码只可重置，不能回显。完整码显示/复制/下载是否写“谁看过”审计以 [ADR-0010](0010-product-freeze-2026-08-20.md) 为准（当前：不写）。
- 公告不作为客户端主流程；更新说明随版本发布。默认更新按现行API/产品合同采用三段版本号、has_update和浏览器打开网盘；原上传manifest/自下载校验安装回滚仅约束明确选用本站包或自更新的产品通道。
- 授权计算以服务端时间和 UTC 为事实，后台展示默认使用 `Asia/Shanghai`；test_only短时套餐仍按首次激活的服务端时刻加套餐duration_seconds计算到期，但客户端本机时间不能改变结果。
- 验收要像管理员、下游、最终客户和攻击者真实使用：页面、接口、持久化、审计/余额/状态四层都一致，不能只点一下按钮。

## 影响

这些规则会进入领域模型、页面文案、错误状态、API 测试和 PR 验收。若将来要改变其中任何一项，先更新本 ADR 或新增 ADR，再改代码。
