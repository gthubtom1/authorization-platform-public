# ADR-0015：全生命周期只使用一套平台密钥

状态：accepted；决定日期2026-09-04。决定保持不变，当前保管与数据边界更新于2026-11-16。

## 背景

原决定发生在已废弃测试候选阶段，当时允许放弃的是该测试账本。当前正式站已有业务，不能把历史“测试数据可清空”解释为清空现行客户数据的授权。

## 决定

所有VPS、测试候选、重装、换机和代码更新均注入同一套既有卡密/额度加密密钥、身份HMAC、Django与发布/授权验签材料及dump口令，不生成第二套。定档、改UI、测试闸加严或重新封存同一份env都不是轮换理由。

材料按gitignored钥匙包README“从这里开始”确认；现行正式站既有env是运行事实，不能再依赖已退役机器或不可解密的旧env包。具体范围与保管入口见根部署05/06，不在ADR保存秘密或复制另一套取用步骤。

本机local环境的开发回退密钥不带上VPS；test/production仍必须注入明确密钥。GitHub令牌、网站证书、公网IP和SSH主机身份不等于卡密锁，可按独立任务调整。

## 后果

旧卡密与客户端验签依赖原密钥连续性，丢失密钥不能靠重建配置修复。钥匙包与旧Git敏感历史须受控保管，不随公开源码包发布；平台密钥轮换或历史改写需单独授权和兼容方案。
