# ADR-0006：服务端可信时间、北京时间展示与短时测试卡

- 状态：accepted
- 日期：2026-08-19
- 领域：授权时间、安全、客户端交接、测试

## 决定

1. 套餐有效期以大于 0 的整数秒保存；分钟、小时和天只是管理端录入单位。1 分钟测试套餐固定归一化为 `duration_seconds=60`，可带 `test_only=true`。
2. 数据库和服务层以 UTC 时间瞬间为事实；`authorization.v1` 在线时间统一使用有符号 64 位 Unix epoch seconds，单位为秒，不使用毫秒、浮点数或 ISO 字符串。后台、报表和统计默认转换为 `Asia/Shanghai`（北京时间）显示和划分自然日。
3. `expires_at` 是排他结束时间。服务端使用可信 UTC 当前时间判断 `server_now >= expires_at`，绝不接受客户端提交的本机时间、时区或到期时间。
4. A 按软件、Profile、授权实例和设备范围保存已接受的最大 `server_time`。客户端使用服务端返回的 `server_time`/`expires_at` 和单调计时辅助倒计时；服务端时间、旧响应或本机墙钟回退统一返回不可重试的 `TIME_ROLLBACK_DETECTED` 并 fail closed。验证、心跳和重启后的授权门必须服从服务端结果，改本机时间、切换时区、重放旧响应或重启不能延长授权。
5. 测试卡与普通卡共享同一授权、设备、撤销和审计状态机；`test_only` 只影响管理端筛选、测试提示和测试验收，不降低安全边界。

## 原因

- VPS 的显示时区可能不同，但时区不应影响同一时间瞬间的授权结果。
- 1 分钟卡可以快速验证新客户端的过期锁定、心跳和重启行为，成本低且不需要分叉业务代码。
- 服务端是唯一授权事实源，能把客户端可修改的本机时钟排除在安全判定之外。

## 代价与边界

- 主机系统时钟仍必须保持同步；生产运行手册需要加入时钟漂移监控。
- 完整空网离线授权不属于本决定；离线宽限必须使用软件策略明确的上限，撤销和封禁不能被宽限覆盖。
- 本 ADR 不决定具体前端组件或最终客户端语言，只固定时间字段、判定权和测试场景。
