# 独立直链站：页面与流程方案

更新时间：2026-11-16。负责人以“就开始编写了”确认进入实现；本文保存认可的简化设计，实际实现与验证以[STATUS](STATUS.md)为准。访客模式：Operate（完成任务）。

本文件已按负责人的补充原位修改。它描述拟实现的行为，不是已通过验收的功能清单，不修改授权平台现有API或软件接入合同。

## 1. 用户只做两件事

**第一次：新建软件 → 选择文件 → 上传 → 复制链接。**

**以后：更新文件 → 选择新文件 → 上传替换。**

软件名称可填可不填。不填时直接显示当前文件名；手工填写名称后，更新文件仍保留这个名称。本站不要求版本号、软件ID、授权配置、更新说明、文件哈希或客户信息，不提供“稍后上传”的空软件下载条目。

版本号在授权平台发布更新时填写。本站只是文件直链工具，不重复做一套软件发版后台。

## 2. 首页只有文件列表

顶栏：直链管理、设置、退出。正文：搜索、新建软件、铺满可用宽度的表格、分页；操作全部独立显示，横纵表格线分隔，窄屏换行。没有额外总览、统计卡片、审核中心或独立批量页面。

以下数据仅用于说明布局，不代表已有文件：

### 固定行数和行高

- 每页可选10或20条，默认10条；记住本浏览器选择，不用每次设置。
- 桌面列表统一行高；长名称/文件名省略显示，可通过聚焦、悬停或文件信息查看完整文本。
- 少于所选条数时保留列表区域高度，以无交互空白补齐视觉，不计入软件总数、不显示复选框、不参与全选。分页区域不因最后一页只有几条而上下跳动。
- 手机端使用同一分页数量、适合窄屏的条目布局；按钮和完整操作可触达，不强行压缩成难点的桌面小字表格。文字放大时允许行高增长。
- 初始空站点显示空状态和“新建软件”，不预装演示软件。

### 操作

- “复制链接”：只复制固定主链接，显示简短成功反馈。剪贴板受限时显示可直接选中复制的地址。
- “更新”：打开文件选择弹窗，只替换这一条。
- “⋯”：改名称、文件信息、恢复上一次文件、暂停/恢复下载、删除。辅助操作收在这里，日常界面保持简单。
- 勾选后显示选中数量和“暂停下载、恢复下载、删除”；单个、多选共用这些动作，不另起“批量中心”。更新文件始终是单条操作。
- 表头只选择本页。改变搜索、翻页或每页数量时清空选择并提示，首版不做跨页或全集选择。
- 删除确认列出名称与数量，并说明固定链接及相关文件将失效；暂停可恢复，删除不能误当成暂停。

## 3. 上传和更新弹窗

```text
新建软件

名称（选填） [留空使用文件名                 ]

            选择电脑上的文件 / 拖入文件

                                  取消    上传
```

```text
更新文件 · 文档助手

当前文件：文档助手.zip

            选择电脑上的新文件 / 拖入文件

固定链接保持不变。

                                  取消    上传替换
```

- 只有文件是必选项，不填写版本号。允许同名新文件替换旧文件，不把“同一版本号内容不同”作为本站的限制。
- 上传中显示真实进度、已传大小、速度/剩余时间的合理估计，以及取消。估计值未稳定时不显示误导数字。
- 传输完成后若尚在拼接/校验，显示“正在校验”，不提前报成功。
- 文件完整落盘、核对通过、记录提交成功后才显示“上传成功”和可复制主链接。
- 初次上传失败不产生可下载的空条目；保留当次任务以便重试。更新失败则保持原文件及链接不变。
- 名称和文件名分开保存。选择不同文件名不改变固定链接，手工名称也不会被悄悄覆盖。

## 4. 固定链接保持不变

例如`https://download.example.com/d/s_7cf3a9`（示例域名，不是真实站点）。条目ID由系统生成，与名称、文件名和软件版本无关。

修改名称、上传新文件不换链接。删除条目或丢失域名会让链接失效，不能承诺删除后仍可下载。

后台为每次完整文件生成内部文件标识，先保存新文件，再切换主链接指向。它不是要求用户填写的新业务字段。

每次开始下载锁定当时那份文件，已有下载不拼接新文件；固定入口不长期缓存当前指向。文件内容地址使用与内容绑定的校验标识，断点续传仍认原文件。

主列表只突出一个固定链接。高级场景下，文件信息可查看内容地址和服务端计算的SHA-256，供授权平台需要校验安装包时使用，不影响普通上传流程。

## 5. 大文件与下载稳定性

不人为设置300MB、500MB或1GB的单文件业务上限。300MB、500MB、1GB及更大的安装包按同一流程处理，但实际接收量必须受可用磁盘和服务资源约束，不能承诺无限空间或无限带宽。

| 场景 | 拟实现行为 |
| --- | --- |
| 管理员上传大文件 | 分块传输、流式落盘，不把整个文件塞进内存；单块请求大小由实现控制，不成为总文件上限 |
| 上传网络中断 | 保留有期限的上传会话和已确认分块；浏览器刷新后提示重新选择同一文件继续，不能假装浏览器仍持有文件；核对文件一致性 |
| 上传结果未知 | 回读原任务状态，重试沿用原操作身份，不重复创建条目或反复替换 |
| 客户下载较大文件 | 文件服务流式发送，支持标准断点续传；不靠应用进程把整个包读入内存 |
| 下载中途断网 | 浏览器/下载器支持续传时，在同一文件仍保留的前提下续传；不保证所有浏览器自动恢复 |
| 客户下载时替换文件 | 已开始的传输使用原文件，新的下载使用切换后的文件 |
| 原文件已不存在或无法确认续传身份 | 明确要求重新下载，不把新文件后半段接到旧文件上 |
| 磁盘不足或同时上传占用太多 | 预留和核算空间后拒绝新的任务，清楚提示；不先删当前文件，不等磁盘写满才报错 |
| 大量并发下载 | 使用文件服务、合理连接限制和背压；过载时短时排队或提示重试，不返回损坏文件 |
| 错传文件 | 更多菜单恢复上一份完整文件，主链接仍不变 |

默认不额外设置每秒下载速度限制，实际速度取决于VPS带宽、用户线路和并发。不能把这个承诺延伸成所有用户满速或任何网络环境都不断线。

### 文件保留和空间

当前文件必须保留，上一份完整文件用于恢复；还在下载的文件不能在传输前被截断。历史文件先保留在本站，文件信息内可以明确确认后清理旧文件，避免无声删除影响下载或外部引用。

未完成上传的临时块自动过期清理，不能无限堆积，也不能误删仍活跃的上传会话。存储用量与剩余空间在设置中只读显示，接近不足时首页显示简短提醒。

不在首版做复杂存储策略面板。上线前确定临时任务有效期、续传保护时间和空间预留，作为有据可调的运行参数。

## 6. 密码和安全：默认生效，不增加上传步骤

管理员必须登录后才能查看管理列表、上传、替换、删除和修改设置。客户持直链即可下载，不要求客户登录管理端或输入管理员密码。

设置页只提供必要内容：修改密码、列表显示偏好、只读存储情况。管理员改密码需核对当前密码、填写新密码并确认；成功后撤销旧会话并重新登录。日常列表不摆一堆安全开关。

| 防护 | 设计要求 |
| --- | --- |
| 猜密码/撞库 | 按可信来源IP及登录行为做有期限的限流、渐进延迟；必要时临时挑战或冷却，不因攻击者连续输错就永久锁死管理员账号 |
| 分布式尝试 | 增加全站异常登录预算和挑战/冷却，失败信息一致，避免公开账号是否存在；不能只靠单IP封禁 |
| 管理密码 | 无默认弱口令；部署时由操作者设置管理员，密码用成熟慢哈希保存；不在公开首次访问页面允许陌生人抢注册 |
| 会话与敏感操作 | HTTPS、受保护的会话Cookie、CSRF、服务端权限校验；设置会话有效期，退出和改密使相应会话失效 |
| 上传文件 | 只作为附件存储和发送，不运行、不自动解压；存储名系统生成，防路径穿越和覆盖服务代码；默认允许安装/压缩包，拒绝作为站点网页直接执行 |
| 修改别人文件/伪造请求 | 所有管理动作在服务端验证登录与目标，不相信浏览器给出的状态；并发更新冲突明确提示 |
| 下载刷流量 | 温和的异常请求和并发保护，分离管理限流与下载限流；不能把正常大文件、同出口多用户或多线程下载一律当攻击，超限短时重试而非永久封禁 |
| 暂停下载 | 主链接和内容地址同时受服务端暂停检查，不能直接绕过静态目录；已开始的传输不承诺立即中止 |
| 运维与记录 | 保留必要操作/登录异常记录，排除密码、会话令牌和平台私钥；数据库与文件成套备份，实际恢复后才能声称可恢复 |

下载入口不依赖“必须从展示网站跳过来”的防盗链规则，否则聊天软件、地址栏和部分下载器会误伤。防刷依靠异常流量识别和并发控制；大规模流量攻击仍需要服务器上游防护，网站代码无法保证带宽永远不被打满。

## 7. 三站配套保持简单

```text
直链站：上传文件 → 固定链接
                      ├─ 填到展示网站的下载按钮
                      └─ 填到授权平台的更新下载地址

授权平台：填写真实软件版本号 → 判断是否提示更新
软件授权接入包：让软件对接授权平台，保持现有JSON与协议
```

直链站不重新登记授权软件身份、不读取卡密/设备/额度，不获得授权平台管理员凭据。三个网站用下载链接配合，不要求互通账号或数据库。

普通“打开下载链接”流程可以长期填写同一个固定链接。只有需要自动校验、自动安装的高级更新，才从文件信息取对应内容地址与哈希，保证它们和授权平台版本记录属于同一份文件；软件版本仍只在授权平台填写。文件替换不会自动修改授权平台的版本和校验信息。

当前接入包及唯一09指令继续有效，本轮不写入未实现接口、不重建已有包，也不让软件客户端携带直链站上传密码。
