# 独立直链站

当前状态：**已部署至 https://files.example.com ，后台入口 /manage/login/。** 2026-11-17正式安装、HTTPS、约1GiB上传/下载校验、固定链接替换、续传、服务重启与隔离恢复均通过。凭据只按根钥匙包13索引查取；实际验证与限制见[STATUS](STATUS.md)。

本目录是独立直链站在这套配套产品中的唯一工作位置。先查看[01-页面与流程方案](01-页面与流程方案.md)，其中包含简化页面、固定链接、大文件下载、密码和防爆破规则，以及开发验收边界。

负责人已明确的日常流程：**新建软件 → 名称可不填 → 选择本地文件 → 上传 → 复制固定链接**。更新只选择新文件，不填写版本号；列表每页10或20行、行高统一。版本号在授权平台填写。

已包含登录、管理列表、分块上传、固定链接、替换、续传、设置、测试和部署材料。正常数据目录默认空站，没有默认管理员；`data/acceptance/`和`test-results/`仅为明确标记的本地验收数据，不随源码交付。

全套配套产品的位置和现状见根目录[配套项目导航](../配套项目导航.md)。授权接入仍从[接入说明/00](../接入说明/00-先读我.md)开始，不在本目录另写一套软件AI接入指令。

## 范围

- 本站提供软件文件上传、稳定下载链接和文件替换。
- 授权规则由现有授权平台负责；本站不复制卡密和心跳系统。
- 展示网站填下载链接即可使用本站，不需要与本站共享账号或数据库。
- 软件项目只需拿授权接入包和该软件的后台JSON，不需要拿到三个网站的源码或管理凭据。

## 后续落地顺序

本地使用与部署交接看[README](README.md)。本轮没有操作VPS；正式部署需另行授权，使用本子项目的安装入口，不运行上级授权平台安装器。

三个网站可以放在同一台VPS上分域名运行，也可以分机部署；实际域名、目标机器和技术实现仍待确定。不人为设置300/500MB一类的单文件业务上限，实际接收量受可用磁盘与资源保护约束。不得把本方案中的示例域名当作真实配置。
