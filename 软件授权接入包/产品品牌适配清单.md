# 产品身份与品牌适配清单

这份清单是软件接入的必做项。`授权启动器模板/` 是通用功能骨架，模板里的标题、图标、示例名称、颜色和文案不能直接作为客户软件的最终界面。

## 接入前先确认

在目标软件项目中记录以下真实资料，来源必须是软件项目本身或负责人确认的信息：

- 产品正式名称、简称、发布者名称和当前版本显示格式
- 主窗口标题、错误提示标题、任务栏/托盘名称、安装器和快捷方式显示名
- 软件图标的源文件和各尺寸输出；至少覆盖窗口、任务栏、托盘、安装器和最终 EXE 使用的图标
- 品牌色、背景色、正文色、错误色、字体和语言
- 客服、购买、公告、更新入口及其显示文案
- 目标软件真实核心 EXE 路径、进程名和启动方式

## 必须完成的替换

1. `platform-binding.json` 中的产品身份必须来自当前软件的 `*-integration.json`，不能继续使用 sample、simulation 或旧软件身份。
2. UI 的 `display_name`、标题和所有用户可见 copy 必须替换为目标软件内容。下载 JSON 只提供平台身份；产品文案仍由软件项目按真实产品确认。
3. 将 `授权启动器模板/ui/app-icon-32.rgba` 替换为目标软件的 32×32 RGBA 图标，并同步替换软件构建系统、EXE 资源、安装器、快捷方式和托盘所使用的图标。只换启动窗口图标不算完整适配。
4. 将 `ThemeTokens` 和 UI profile 中的颜色、语言、模块文案改成目标软件的品牌配置；不得保留模板默认的“软件授权”、示例产品名或示例品牌色。
5. 保留授权协议、设备身份和核心功能门的语义；品牌适配不能通过改 product_id、profile_id、公钥、installation_id 或平台 URL 完成。

运行时窗口标题会从已加载并校验的产品 manifest `display_name` 取得。图标仍是随产品构建打包的资源，必须由软件项目提供并替换；模板示例图标不能进入正式发布物。

## 发布前检查

- 在源码、资源、构建脚本、安装器、快捷方式和最终 EXE 的用户可见资源中搜索模板残留：`软件授权`、`a-template`、`sample`、`simulation`、模板图标和模板默认品牌色。
- 检查窗口标题、错误框、任务栏、托盘、安装器、卸载器、快捷方式和 EXE 文件属性是否统一使用目标软件身份。
- 启动已授权和未授权两种状态，检查登录页、状态页、设备码、公告、购买、客服、更新和错误页面的品牌一致性。
- 生成最终交接文档，记录产品名称、图标源/哈希、替换文件、最终 EXE 哈希、检查命令和未完成项。
- 任一模板残留、默认图标或未确认的产品身份存在时，结论只能是 `PARTIAL`，不能发布为已接入。
